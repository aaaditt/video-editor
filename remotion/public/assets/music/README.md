# Music beds

Drop royalty-free music files (`.mp3` / `.wav`) here. The auto-draft engine
picks the first file alphabetically when a preset wants music; reference a
specific file in `edit-plan.json` as `assets/music/<name>`.

Audio files in this folder are gitignored — only this README is committed.
Good sources: YouTube Audio Library, pixabay.com/music, incompetech.com.
